# Data Analysis & Machine Learning Notebooks

This repository contains a collection of **Python and Jupyter Notebook–based implementations** developed as part of my academic and self-learning journey in **Civil Engineering, Transportation Engineering, and Data Analytics**.

The notebooks reflect hands-on experimentation and implementation by the author. They were independently implemented and experimentally validated as part of academic and self-learning activities.

The notebooks demonstrate applications of **data analysis, visualization, time-series analysis, and machine learning** techniques, with a focus on **traffic and transportation-related problems**.

---

##  Repository Structure

- **Undergrad Thesis/**  
  Research work related to my undergraduate thesis, including
  1. Raw data processing, cleaning
  2. Traffic trend visualization and analysis
  3. model development, and forecasting.

- **Practise Online Course/**  
  Practice notebooks developed while completing online courses and self-learning modules.

- **Data_Visualization.ipynb**  
  Exploratory and advanced data visualization techniques using Python libraries including:
  1. Matplotlob
  2. Advanced Matplotlib
  3. Seaborn
  4. Multiplot
  5. Regression plot
  
- **EDA.ipynb**  
  Exploratory Data Analysis (EDA) methods for structured datasets.
  1. Univariate analysis
  2. Multivariate analysis

- **Deep_Learning_with_Neural_Network.ipynb**  
  Introduction to neural networks and deep learning concepts.
  1. Build classification model using Fashion MNIST Dataset
  2. Using CallBack Function to Control Training
  3. Training, validating, predicting 

- **Time_Series_Analysis_Fundamental.ipynb**  
  Fundamental concepts of time series analysis applied to real-world data.
  1. Statistical forecasting
  2. Traning a single layer neural network
  3. Simple Recurrent Neural network forecasting
  4. Convolutions with LSTM (Hybrind modeling)
  5. Basic of Transfer Learning

- **Time_Series_Analysis_Advanced.ipynb**  
  Advanced time series modeling and forecasting techniques.
  1. Auto Regression (AR), Autoregression integrated Moving Average ARIMA,  Vector Auto Regression (VAR), Seasonal Arima (SARIMA)
  2. Univariate, Multivariate time series analysis
  3. RNN modeling (LSTM, GRU)

- **TensorFlow_Basic.ipynb**  
  Basic implementation of deep learning models using TensorFlow.

- **PyTorch_Basic.ipynb**  
  Fundamental deep learning workflows using PyTorch.

- **Transfer_Learning.ipynb**  
  Transfer learning techniques and applications.

- **Python_and_its_Library.ipynb**  
  Overview of Python programming and commonly used scientific libraries.
